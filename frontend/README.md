# Frontend (Djosu Good Deeds)

Next.js UI для API из `backend/`. Полный быстрый старт, переменные окружения и CI — в [корневом README](../README.md).

Архитектура слоёв (FSD): [docs/FSD.md](docs/FSD.md).

```bash
cp .env.example .env.local
npm ci
npm run dev      # http://localhost:3000
npm run lint
npm run test
npm run build
```
